# Weekly Lessons

Each lesson folder contains the actual week's instruction, not only a topic name.

## Lesson workflow

1. Start with the prerequisite retrieval questions.
2. Study the primary explanation and one alternate representation.
3. Read the relevant official documentation.
4. Draw the mental model before coding.
5. Complete the guided lab.
6. Attempt the independent assignment without copying a solution.
7. Apply one small concept to the capstone.
8. Complete the knowledge check and teach-back.
9. Update `tracking/WEEKLY_PROGRESS.md`, `tracking/SKILLS_MATRIX.md`, and `tracking/SPACED_REPETITION.md`.

Use `templates/WEEKLY_LESSON.md` as the template for future weeks.
