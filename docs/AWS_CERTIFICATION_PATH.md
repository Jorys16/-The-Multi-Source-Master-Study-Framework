# AWS Certification Path

These certifications reinforce the curriculum. They are not substitutes for practical experience or a deployed portfolio.

## 1. AWS Certified Developer – Associate (DVA-C03)

**Study after:** application development, APIs, IAM fundamentals, testing, deployment, and troubleshooting.

Official page: https://aws.amazon.com/certification/certified-developer-associate/

Preparation:
- Read the current exam guide and identify its domains.
- Practice IAM roles/policies, SDKs, storage, managed services, application security, CI/CD, and debugging.
- Complete labs and apply relevant services to the capstone.
- Take a practice exam and close knowledge gaps before booking.

## 2. AWS Certified Machine Learning Engineer – Associate (MLA-C02)

**Study after:** Python data processing, statistics, ML workflows, feature engineering, model training/evaluation, and model deployment.

Official page: https://aws.amazon.com/certification/certified-machine-learning-engineer-associate/

Preparation:
- Verify current exam availability and language status on AWS.
- Study data preparation, model development, deployment/orchestration, monitoring, and security.
- Use a reproducible ML experiment and an operational model workflow as project evidence.

## 3. AWS Certified Generative AI Developer – Professional (AIP-C01)

**Long-term goal:** after meaningful production application and GenAI implementation experience.

Official page: https://aws.amazon.com/certification/certified-generative-ai-developer-professional/

Preparation:
- Verify current exam guide and eligibility recommendations.
- Build and operate a production-oriented RAG/agent application.
- Measure quality, security, latency, reliability, and cost.
- Demonstrate agent workflows, evaluation, governance, and troubleshooting.

## Certification rules

- Do not book an exam solely because the corresponding study week has arrived.
- Verify exam version, availability, current guide, and costs on the official AWS site.
- Use the exam guide as a gap map, not as the entire curriculum.
- Prioritize one cloud ecosystem rather than collecting duplicate provider badges.
- Keep the weekly study budget near 20 hours total.
