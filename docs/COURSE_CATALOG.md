# Course Catalog

This catalog groups the curriculum into coherent schools. Weekly sequencing is in [ROADMAP_40_WEEKS.md](ROADMAP_40_WEEKS.md).

## School 01 — Computer Science and Software Engineering
- Computing systems: binary, CPU, memory, processes, runtimes, compilers, interpreters.
- Programming foundations: Python, C++, control flow, functions, modules, types, exceptions.
- Object-oriented design, RAII, ownership, standard libraries.
- Data structures, algorithms, complexity, problem solving.
- Git, testing, debugging, code quality, documentation, SDLC.

## School 02 — Full-Stack Engineering
- HTML, CSS, semantic markup, accessibility, responsive design.
- JavaScript, browser runtime, DOM, event loop, async/await, fetch.
- TypeScript, React, components, state, hooks, routing, forms.
- HTTP, REST, Node.js, Express, middleware, validation, API contracts.
- SQL, PostgreSQL, relational modeling, transactions, indexes, query optimization.
- Authentication, authorization, application security, testing, CI/CD, deployment.

## School 03 — Data Engineering and Systems
- Python data processing, NumPy, pandas, CSV/JSON, validation.
- ETL/ELT, normalization, provenance, data quality, reproducibility.
- PostgreSQL internals, query planner, indexing, transactions.
- Data access controls, tenant isolation, lineage, retention.

## School 04 — Mathematics and Statistics
- Algebra and functions.
- Linear algebra: vectors, norms, dot products, matrices, transformations.
- Calculus and gradients at a practical level.
- Probability, distributions, sampling, statistical inference.
- Optimization, numerical computing, and evaluation metrics.

## School 05 — Machine Learning and Deep Learning
- Supervised and unsupervised learning.
- Features, train/validation/test, leakage, generalization.
- Classification and ranking metrics, error analysis.
- Neural networks, backpropagation, optimization.
- PyTorch, tokenization, attention, transformer architecture.
- Data quality and experiment tracking.

## School 06 — Applied AI and LLM Engineering
- Generative AI concepts, prompting, structured output, context engineering.
- Model APIs, provider abstraction, streaming, retries, rate limits.
- Embeddings, chunking, document ingestion, provenance.
- RAG, pgvector, exact/approximate search, hybrid retrieval, reranking.
- Evaluation, golden datasets, relevance, faithfulness, latency, cost.
- Tool calling, agent workflows, state, memory, MCP, bounded orchestration.

## School 07 — Identity, Access Management, and AI Agent Security
- Digital identities, principals, authentication, authorization.
- Passwords, MFA, passkeys, sessions, cookies, certificates, signed tokens.
- OAuth 2.0, OpenID Connect, access/refresh tokens, scopes.
- RBAC, ABAC, least privilege, policy evaluation, policy-as-code.
- API authorization, multi-tenant isolation, audit, provisioning and deprovisioning.
- Service accounts, workload identity, secrets, short-lived credentials.
- AWS IAM, role assumption, trust policies, resource and identity policies.
- Delegated user access vs autonomous agent identity.
- Agent owners, lifecycle, tool scopes, approvals, audit, revocation.
- MCP security, prompt injection, privilege escalation, incident response.
- SPIFFE/SPIRE and Open Policy Agent/Rego concepts.

## School 08 — Cloud, DevOps, and Production AI
- Linux, CLI, networking, cloud concepts, AWS.
- IAM roles, storage, databases, app hosting, containers and serverless.
- Docker, CI/CD, infrastructure as code.
- Secrets management, configuration, security boundaries.
- Observability, logs, traces, metrics, evaluation and feedback loops.
- Performance, resilience, rollback, service objectives, cost controls.

## School 09 — Professional Engineering and Capstone
- Requirements, user stories, acceptance criteria, prioritization.
- Architecture diagrams, ERDs, API contracts, ADRs.
- Agile planning, issues, branches, pull requests, code reviews.
- Security reviews, testing strategy, technical writing.
- Portfolio, demo, technical defense, interview preparation.
