# Program Charter

## Mission

Develop the ability to design, build, test, secure, deploy, operate, and explain full-stack AI applications. The aim is practical engineering capability supported by strong fundamentals, not superficial familiarity with tools.

## Target profile

A full-stack software engineer with applied AI/LLM engineering capability and a meaningful specialization in Identity and Access Management (IAM) and AI agent security.

This is a product-engineering path. It includes mathematical and ML foundations but is not intended to replace a research-focused graduate ML curriculum.

## Outcomes

By the end of the program, the learner should be able to:

1. Explain how programs run, how memory and data structures work, and how to reason about algorithmic cost.
2. Build maintainable applications with TypeScript, React, Node.js, Express, SQL, and PostgreSQL.
3. Write Python for data processing, ML experiments, evaluation, and AI services.
4. Use C++ to strengthen systems understanding, resource ownership, and algorithmic reasoning.
5. Design relational data models, transactions, indexes, and query performance investigations.
6. Build an evaluated RAG system using embeddings, pgvector, hybrid search, and evidence provenance.
7. Build bounded tool-using agents and understand state, memory, orchestration, and MCP.
8. Design identity, authentication, authorization, roles, attributes, workload identities, and audit trails.
9. Protect agent tools and private data with least privilege, server-side policy enforcement, approval gates, and revocation.
10. Deploy and operate cloud applications with security, observability, reliability, and cost controls.
11. Explain architecture decisions, limitations, tests, and measured outcomes to another engineer.

## Calendar

- Program start: 16 November 2026
- MVP v1 target: 16 May 2027
- Program end: 22 August 2027
- Time budget: approximately 20 hours per week

The calendar is a planning framework. Advancement depends on demonstrated competence, not the passage of dates.

| Work type | Hours/week |
|---|---:|

| Guided labs | 5 |
| Independent assignments | 4 |
| Capstone engineering | 5 |
| Review and assessment | 2 |
| **Total** | **20** |

IAM/security, certification preparation, and conceptual redundancy are integrated into these hours rather than added as separate workloads.

## Technology strategy

- TypeScript/JavaScript: primary language for product UI and web APIs.
- Python: primary language for data engineering, ML, RAG, evaluation, and AI services.
- C++: supporting track for systems concepts, algorithms, memory, and performance reasoning.
- PostgreSQL: primary relational database and, through pgvector, vector storage.
- AWS: primary cloud-learning ecosystem; choose services based on product needs and cost.
- IAM standards and tools: learn general identity principles first, then compare AWS IAM, Microsoft Entra, OIDC/OAuth, SPIFFE/SPIRE, and policy-as-code tools.

## Definition of program success

A portfolio-ready, deployed capstone plus evidence of learning: source code, tests, architecture diagrams, API contracts, database schema, RAG evaluation report, IAM threat model, access-control tests, operational evidence, and a technical presentation.

No course, certificate, or project guarantees employment or mastery. Continued practice, feedback, and professional experience remain necessary.
