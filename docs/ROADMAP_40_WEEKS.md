## Parallel strands

### IAM and agent security

IAM is woven into the weekly sequence:
- W01–06: identity, principal, trust boundary, process identity.
- W07–10: browser identity, cookies, sessions, client-side auth state.
- W11–12: backend authentication concepts, authorization middleware, RBAC, ownership checks.
- W13–16: user/role/resource schema, tenant isolation, secret handling, AWS IAM foundations.
- W17–20: data pipeline access, service roles, workload identity, provenance.
- W21–26: model credentials, authorization-aware RAG, cross-tenant isolation, protected retrieval.
- W27–31: agent identity, delegated vs autonomous access, tool scopes, MCP trust boundaries, approval gates, revocation.
- W32–36: zero trust, workload identity, governance, privileged access, audit, incident response.
- W37–40: security architecture, threat model, access review, authorization test matrix, capstone defense.

### AWS certifications

- Developer Associate: study after application, API, IAM, testing, and deployment foundations.
- Machine Learning Engineer Associate: study after data/ML foundations and model deployment.
- Generative AI Developer Professional: advanced goal after meaningful production application and GenAI experience.

Verify exam status, exam guides, and availability directly from AWS before booking. Certification study is not a replacement for project evidence.
