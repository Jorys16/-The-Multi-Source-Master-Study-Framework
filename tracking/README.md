# Tracking System

This folder is the source of truth for progress and evidence.

## Files

- [Weekly Progress](WEEKLY_PROGRESS.md): weekly status, time, evidence, blockers, and retrospective.
- [Skills Matrix](SKILLS_MATRIX.md): competency level and proof for each skill.
- [Spaced Repetition](SPACED_REPETITION.md): schedule reviews so concepts remain retrievable.
- [MVP Milestones](MVP_MILESTONES.md): product milestones and acceptance criteria.

## Status vocabulary

- Not Started
- In Progress
- Blocked
- Needs Review
- Complete

## Update rules

1. Update weekly progress at the end of each study week.
2. Link commits, issues, pull requests, test output, diagrams, and demos as evidence.
3. A week is not Complete until its mastery gate is met.
4. Mark skills based on evidence, not confidence alone.
5. Move incomplete concepts into spaced repetition.
6. Record blockers precisely: expected behavior, actual behavior, reproduction steps, error, and attempts.
7. Keep sensitive credentials, personal documents, and private employer data out of this public repository.

## Privacy

This repository is public. Track learning progress and sanitized evidence only. Do not commit resumes, tokens, personal identifiers, private study records, or any confidential data.
